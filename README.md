# Avito Clone - Мини-сервис объявлений

Учебный проект - локальный аналог Avito на Django с PostgreSQL в Docker.

## Функционал

- ✅ Публикация объявлений по категориям
- ✅ Просмотр списка и карточки объявления
- ✅ Фильтрация по категориям
- ✅ Поиск по заголовку и описанию
- ✅ Регистрация и авторизация пользователей
- ✅ Создание, редактирование и удаление своих объявлений
- ✅ Загрузка изображений к объявлениям
- ✅ Счётчик просмотров
- ✅ Контакты автора (email, телефон)
- ✅ Активация/деактивация объявлений
- ✅ Пагинация
- ✅ Админка Django

## Требования

- Docker
- Docker Compose
- Git

## Установка и запуск

### Шаг 1: Клонирование репозитория

```bash
git clone <URL_вашего_репозитория>
cd avito-project
```

### Шаг 2: Настройка переменных окружения

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

При необходимости измените значения в `.env` (секреты, пароли и т.д.).

**ВАЖНО:** Никогда не коммитьте файл `.env` в Git!

### Шаг 3: Запуск приложения

```bash
docker compose up --build
```

Эта команда:
- Скачает образ PostgreSQL 15
- Построит Docker-образ для Django
- Создаст и запустит контейнеры
- Применит миграции к базе данных

### Шаг 4: Создание суперпользователя (для админки)

В новом терминале выполните:

```bash
docker compose exec web python manage.py createsuperuser
```

Следуйте инструкциям для создания учётной записи администратора.

### Шаг 5: Открытие в браузере

- **Основной сайт:** http://localhost:8000
- **Админка Django:** http://localhost:8000/admin

## Создание категорий

После первого запуска необходимо создать категории через админку:

1. Войдите в админку: http://localhost:8000/admin
2. Перейдите в раздел "Категории"
3. Нажмите "Добавить категорию"
4. Создайте минимум 3-5 категорий, например:
   - Электроника (electronics)
   - Услуги (services)
   - Животные (animals)
   - Одежда (clothes)
   - Недвижимость (realty)

Поле "Слаг" заполнится автоматически на основе названия.

## Основные команды Docker

### Запуск приложения

```bash
docker compose up --build
```

### Запуск в фоновом режиме

```bash
docker compose up -d
```

### Остановка приложения

```bash
docker compose down
```

### Остановка с удалением volumes (база данных удалится!)

```bash
docker compose down -v
```

### Просмотр логов

```bash
docker compose logs -f web
```

### Применение миграций вручную

```bash
docker compose exec web python manage.py migrate
```

### Создание миграций (после изменения моделей)

```bash
docker compose exec web python manage.py makemigrations
```

### Запуск Django shell

```bash
docker compose exec web python manage.py shell
```

## Модели данных

### Category (Категория)
- name - название категории
- slug - URL-идентификатор
- description - описание (необязательно)

### Ad (Объявление)
- title - заголовок
- description - описание
- price - цена (необязательно)
- category - категория (ForeignKey)
- author - автор (User)
- image - изображение (необязательно)
- status - статус (active/inactive)
- views - счётчик просмотров
- contact_email - контактный email (необязательно)
- contact_phone - контактный телефон (необязательно)
- created_at - дата создания
- updated_at - дата обновления

## Troubleshooting

### Ошибка подключения к базе данных

Убедитесь, что контейнер базы данных запущен:

```bash
docker compose ps
```

Если база не запустилась, проверьте логи:

```bash
docker compose logs db
```

### Миграции не применились

Примените вручную:

```bash
docker compose exec web python manage.py migrate
```

### Ошибка с файлами media

Убедитесь, что volume `media_volume` подключён в `docker-compose.yml`.
